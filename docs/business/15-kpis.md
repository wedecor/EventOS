This document defines:

1. **What We Decor measures today** vs **Not Currently Measured**

## 5. Phase 1 Measurement Priorities (Event OS)

### Phase 1 Founder Dashboard — Top 5 KPIs

For Event OS Phase 1 founder dashboard:

1. **Total Enquiries**
   - Number of new enquiries received
2. **Conversion Rate**
   - Percentage of enquiries converted into confirmed bookings
3. **Events Completed**
   - Number of events successfully completed in a period
4. **Event Profitability (Gross Margin)**
   - Revenue minus direct event costs (profit per event)
5. **Lead Source Performance**
   - Conversion and booking performance by source (Instagram Ads, organic, website, referrals, etc.)

Purpose: visibility into growth, sales performance, operations output, profitability, and marketing effectiveness.

### Measurement Status (Current State)

| KPI | Current measurement status |
|-----|---------------------------|
| Total Enquiries | **Partially measured** (Lead Management Application; informal when ads paused) |
| Conversion Rate | **Partially measured** (~10% overall approximate in `02`) |
| Events Completed | **Partially measured** (informal) |
| Event Profitability (Gross Margin) | **Not Currently Measured** (Phase 1 requirement from `09`) |
| Lead Source Performance | **Partially measured** (source tagged; end-to-end conversion by source **Not Currently Measured**) |

### Cross-reference — Operations priorities (`05-event-execution.md`)

Founder operational measurement priorities (may be Phase 2 dashboard or ops view):

1. On-time completion rate  
2. Events completed per month  
3. Same-day multi-event count  
4. Customer complaints during execution  
5. Setup duration by event type  

### Future Vision

Phase 1 founder dashboard focuses on the top 5 KPIs above; operational KPIs from Doc 05 can extend dashboards in later phases.
